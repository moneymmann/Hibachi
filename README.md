# hibachi-spread-capture-pro

이 프로젝트는 수익을 보장하지 않습니다. Maker spread capture에는 one-sided fill risk가 있습니다.
전용 서브계정을 사용하세요. 첫 라이브는 작은 `max_order_notional_usdt`로 시작하세요.
API 키는 절대 커밋하지 마세요.
대시보드: http://127.0.0.1:8787/dashboard
로그: logs/audit.jsonl

## Quick Start (Windows PowerShell)
1. 저장소 클론
2. 루트에 .env 배치
3. `scripts/RUN_SETUP.bat` 더블클릭
4. `scripts/RUN_DRY_RUN_UI.bat` 더블클릭
5. dry-run 검증 후 `scripts/RUN_LIVE_UI.bat` 더블클릭
